Import an Anki Deck

An .apkg file is an Anki export — a zipped SQLite database. This reads Basic and Basic (and reversed) note types, which cover the large majority of decks. Cloze deletions and card types with extra template logic are imported using their raw field text, since re-deriving Anki's cloze rendering isn't reliable outside Anki itself.

Paste Your Q&A Content

Format: each question on its own line, its answer on the line(s) after it.
Questions start with Q: or a question word (What / How / Why / Does / Is / Are / Which / Where / When / Can / Should).
Answers start with A: or a bullet (-, •, *) — or just follow directly on the next line.

Example:
What causes fever?
Infection, inflammation, or malignancy
